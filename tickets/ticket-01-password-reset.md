# Ticket 01 - Password Reset

## User
John Smith

## Department
Sales

## Issue
User was unable to log into the domain environment after forgetting their password.

## Troubleshooting Steps
- Verified account existed in Active Directory Users and Computers
- Confirmed account was not disabled
- Reset password through Active Directory
- Enabled "User must change password at next login"

## Resolution
User successfully regained access to the domain account after password reset.
