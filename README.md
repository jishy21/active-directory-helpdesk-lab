# Active Directory Help Desk Home Lab

## Overview
This project simulates a real-world enterprise Active Directory environment using Windows Server 2022 and VirtualBox. The lab was built to practice common IT support and help desk tasks including user provisioning, password resets, security group administration, account disablement, and domain management.

## Technologies Used
- Windows Server 2022
- Active Directory Domain Services
- VirtualBox
- Windows Administration Tools
- Group Policy Management
- GitHub Documentation

## Skills Practiced
- Active Directory Administration
- Organizational Unit (OU) Management
- User Account Provisioning
- Security Group Management
- Password Resets
- Account Disablement
- Domain Controller Deployment
- Help Desk Ticket Documentation
- Windows Server Troubleshooting

## Lab Environment
- Domain: jmlab.local
- Domain Controller: DC-01
- Client: CLIENT.001

## Project Structure
```text
tickets/      -> Help desk ticket simulations
```

## Example Tasks Completed
- Created multiple organizational units and domain users
- Configured security groups for departments
- Simulated password reset requests
- Disabled and managed inactive user accounts
- Joined a Windows client workstation to the jmlab.local domain
- Verified DNS and network connectivity between CLIENT-01 and DC-01
- Successfully tested domain user login from a client workstation
- Documented domain login testing through help desk ticket format
- Resolved Active Directory prerequisite conflicts during deployment
